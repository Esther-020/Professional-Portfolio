Professional Reflection

What I Have Learned

During my studies, I have developed a better understanding of Computer Science and the importance of practical technical skills. I have learned programming concepts using Java, including classes, objects, constructors, arrays, ArrayLists, inheritance and object-oriented programming. Working on programming exercises has helped me understand how theoretical concepts can be applied to create practical solutions.

My Strongest Skill

One of my strongest IT skills is problem solving. When working on programming tasks, I have learned how to analyse a problem, identify errors and make changes to improve my programs. Debugging has taught me to be patient and to approach problems step by step rather than giving up when something does not work.

A Skill I Want to Improve

One skill I would like to improve is web development. I want to become more confident with HTML, CSS and JavaScript so that I can create professional and responsive websites. Creating this portfolio is helping me gain practical experience in this area.

My Development Plan

To improve my web development skills, I plan to practise regularly by creating small websites and personal projects. I will also learn more about responsive design, JavaScript and modern web development techniques. Practising through real projects will help me understand how different technologies work together.

How My Portfolio Can Help My Career

This portfolio can support my future studies and career by providing a place where I can demonstrate my projects, technical skills and professional development. I can continue adding new projects, skills and achievements as I progress through my studies. In the future, I can share this portfolio with potential employers when applying for internships or IT positions.
